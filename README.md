# Khoi Git

Bộ cài Khoi Git — app git có giao diện kiểu GitKraken.

Tải bản mới nhất ở mục [Releases](https://github.com/DinhVietKhoi/khoi-git-releases/releases/latest):

- Mac chip Apple (M1/M2/M3…): `Khoi-Git-x.y.z-mac-arm64.dmg`
- Mac Intel: `Khoi-Git-x.y.z-mac-x64.dmg`
- Windows: `Khoi-Git-x.y.z-win-x64.exe`

Mac: lần đầu mở bấm chuột phải vào app → Open (app chưa ký).
Cài rồi thì app tự báo khi có bản mới.
